# Bandaru Sasikiran — Portfolio

A single-page, cinematic portfolio site for **Bandaru Sasikiran** — Advanced App Developer Analyst at Accenture, training in Databricks Data Engineering.

🌐 **Live site:** https://sasivirat135.github.io/my-portfolio/

## Highlights

- Single self-contained `index.html` — no build step, no dependencies
- Live data-network particle background with cursor interaction
- Typewriter role line, shimmering gradient name, animated counters
- Flowing "Extract → Transform → Load → Visualize" data pipeline
- 3D-tilt project cards, custom cursor, scroll progress bar
- Fully responsive, respects `prefers-reduced-motion`

## Tech

Plain HTML, CSS, and vanilla JavaScript. Fonts from Google Fonts (Inter + JetBrains Mono).

## Deployment

Deployed automatically to GitHub Pages via GitHub Actions on every push to `main`
(see [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)).

To run locally:

```bash
python -m http.server 5500
```

Then open http://localhost:5500
